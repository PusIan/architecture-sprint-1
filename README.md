Уровень 1. Проектирование

Приложение web состоит из следующих компонентов:
 - Регистрация (Register.js)
 - Авторизация (Login.js)
 - Информация об успешной авторизации (InfoTooltip.js)
 - Изменение данных профиля (EditProfilePopup.js)
 - Извенение аватара (EditAvatarPopup.js)
 - Добавление места (AddPlacePopup.js)
 - Отображение картинки на весь экран (ImagePopup.js)
 - Работа с карточкой (Card.js), которое включает в себя: лайк, удаление карточки, и отобрашение картинки в развернётом виде.
 - Footer.js (низ страницы)
 - Header.js (Заголовок страницы), отображает профиль, под которым авторизован пользователь

 Предлагается подилить фронтент на три микрофронтенда:
  - users, будет включать в себя компоненты связанные с пользователем (регистрация, авторизация, аватар, изменение данных профиля)
  - cards, будет включать в себя компоненты связанные с местом, их добавлением, удалением, лайком и отображением на весь экран
  - hosts, которое будет главной точкой входа

Таким образом мы придерживаемся принципу вертикальной нарезки.
Команда "users" будет отвечать за стили, форму и бизнес логику связанные с пользователем.
Аналогично команда "cards" будет отвечать за стили, форму и бизнес логику связанные с карточками, их отображением, лайками и т.д.
Кодовая база будет в одном репозиторие.
Мы будем использовать Module Federation.
Module Federation — это мощная функция Webpack (начиная с версии 5), 
которая позволяет нескольким независимым приложениям (или частям одного большого приложения) 
делиться модулями во время выполнения. Это особенно полезно при построении микрофронтендов. 
Module Federation основан на функции lazy loading.
